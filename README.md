# Wazuh Home SOC Lab

A hands-on Security Operations Center (SOC) lab focused on security
monitoring and analysis using Wazuh.

## Tools Used

- Wazuh
- Kali Linux
- Linux
- VirtualBox

## Project Work

- Configured Wazuh for endpoint security monitoring.
- Monitored and analyzed security events and alerts.
- Investigated authentication failures and suspicious login activity.
- Generated a Wazuh Security Events Report.

## Key Findings

The report identified multiple security events, including:

- Failed SSH authentication
- Multiple failed login attempts
- Excessive authentication attempts
- SSH brute-force activity
- Sudo activity
- Host-based anomaly detection

The security-events report is included in this repository.
